# Lagerverwaltung mit Java

Das ist mein erstes Java-Projekt. Ich habe ein einfaches Lagerprogramm geschrieben, um Java zu üben.

## Funktionen

- Neue Produkte hinzufügen
- Mengen von vorhandenen Produkten erhöhen
- Produkte aus dem Lager entfernen
- Den aktuellen Lagerbestand anzeigen
- Prüfen, welche Produkte in welchem Regal liegen

## Ausführen
Java muss installiert sein. Das Programm kann in IntelliJ IDEA gestartet werden.

## Was ich dabei gelernt habe?
Bei diesem Projekt habe ich mit Arrays, Methoden, Schleifen, Bedingungen und Benutzereingaben mit Scanner gearbeitet.
